Verified Results

Reproducible via Code

All results below are generated directly from the repository test suite. One continuous scale A is fit to the data — the four spectral indices {1, 12, 17, 40} are chosen to match the masses too, not derived from an independent rule (Open Problem #1, below). "Verified" here means numerically verified by the test suite; none of it is machine-checked. The Lean-checked Evgeny's Theorem is a separate result (non-Abelian SU(2), fourth-moment trace defect) and does not bear on these claims.

Verified
△⁵
Sierpiński Gasket Spectral Theory
Spectral decimation ×5 — eigenvalues scale by factor ~5 between consecutive levels (exact for small λ). Weyl law N(λ) ~ λ^{d_s/2} with d_s/2 = ln(3)/ln(5) ≈ 0.6826. Log-periodic oscillations with period ln(5). A window-free chord estimator recovers the exponent to better than 0.1% (level 9, N ≥ 1000).
d_s/2 = 0.6826

Full π-flux through all holes opens a mass gap: first eigenvalue jumps from ~0.006 to ~0.46 at level 5. Partial twists also gap the spectrum. Gap-selected indices follow lacunary 3^k − 1 structure.

Open Problems

What Remains Unsolved

The mass formula m = A·n is numerically accurate, but n is not derived from spectral properties. Status of each item as of v2.2.0.

#1
Searched · no evidence

Selection Rule for n_f

Three pre-registered look-elsewhere tests found no operator configuration that selects n ∈ {1, 12, 17, 40} more often than chance. Reopen only with a derivation of the indices, or a new family with an a-priori rationale under a new pre-registered protocol.

  • Tried: Z₂ twists, scalar potentials, Dirichlet corners, SG × S¹ (lattice and continuum circle), carpet
  • Untested: random dendrites, higher-genus or branched coverings
#2
Resolved

Finite-Level Convergence of d_s/2

Regression fits depend on the window phase (spread about ±3.5% for a 3-period window), a property of the estimator, not of the level. A window-free chord estimator recovers ln3/ln5 to better than 0.1% (level 9, N ≥ 1000).

  • Exact counts up to level 10
  • Decimation holds only up to corner-defect corrections for this Laplacian
#3
Open

Light Fermions

Electron, up, down, strange quarks are not addressed. They need a specified model whose parameters are counted against the masses it explains; no Lagrangian is defined in this repository.

  • Not started

Research archive · 2026

The history behind the numbers

Phi-Genesis is not a claim of a completed mass-selection theory. It is a documented investigation into whether fractal spectral structure can independently select the proposed integer indices—and what careful testing found.

01 / ORIGIN

The original question

Could spectral gaps on a self-similar graph select the target indices without using the measured masses to choose them?

Explore the timeline ↗ 02 / REASSESSMENT

The look-elsewhere problem

An exciting exploratory match prompted a wider audit of how many configurations had been tried and how rare the result really was.

Read the reassessment ↗ 03 / CORRECTION

Power before interpretation

The first protocol could not reach its own decision threshold, even under a perfect hit. Later designs checked power using null-only draws.

See the methodological lessons ↗ 04 / CURRENT STATUS

What the evidence supports

The tested families did not establish an independent rule for {1, 12, 17, 40}. The record distinguishes this bounded negative result from a universal impossibility claim.

Self-Referential Symlink
Commit aee047d shipped a git-tracked symlink phi_genesis → . as an import workaround. pytest's directory walker recursed into it infinitely: the same 14 tests rediscovered 33 times over, inflating a ~2 minute run to 33m45s before the OS-level symlink-depth limit finally cut it off.

Fixed
✓
Real Package Directory
Commit a1a66c9 replaced the symlink with an actual phi_genesis/ package, relative imports, and a proper pyproject.toml — installable regardless of what the checkout folder is named, no recursion possible.

# Support and Research Correspondence

Phi-Genesis is a reproducible numerical research project. Methodological criticism, requests for clarification, and reproducibility reports are welcome when they identify the relevant source file, commit, test command, or protocol version.

## Reporting a reproducibility issue

Include, where applicable:

- repository commit or release;
- operating system and Python version;
- exact command and complete error output;
- input data or random seed;
- whether the result is expected to be numerical, statistical, or a formal proof.

## Scientific scope

Please distinguish the numerical results in Phi-Genesis from the separate Lean formalization of Evgeny's Theorem. A numerical match for \(m=A n\) is not an independently derived mass prediction, and the target-index selection problem remains open in the documented search families.

# Data, Provenance and Research Records

Phi-Genesis maintains a distinction between source code, committed numerical artifacts, protocol commitments and later interpretation. This separation is essential because the research includes negative findings and reassessments of earlier apparent matches.

## Authoritative record hierarchy

1. **Preregistration** — the question, target set, rule, null ensembles, parameters and decision threshold fixed before evaluation.
2. **Code and data** — the implementation, seeds, null pools and numerical outputs used in the test.
3. **Protocol ledger** — the cumulative account of tested configurations, including exploratory and abandoned branches.
4. **Methodology** — explanation of the statistical reasoning and interpretation limits.
5. **README and changelog** — project-level summary and version history.
6. **Website and interactive portal** — navigational and explanatory views, subordinate to the primary records.

## Current documented record

The current public project status is v2.2.1. The cumulative protocol ledger records 193 main-family configuration evaluations and an earlier carpet search of about 128 level-3 configurations plus an unrecorded level-4 sweep. Therefore the honest cumulative count is **at least about 321**, not a falsely precise total.

The carpet branch is marked abandoned after a null analysis reassessed its initial 4/4 match as consistent with a look-elsewhere effect. Protocol v1.0's power limitation is also explicitly documented; it is not treated as an informative negative.

## Provenance and limitations

- Do not present the four target indices as independently derived from the spectral operator.
- Do not treat all target hits as equally informative: the base-rate audit found index 1 to be common under the tested ratio rule.
- Do not describe the η-invariant value −4 as reproduced; the documented tests did not observe it.
- Do not transfer the Lean verification status of Evgeny's Theorem to the separate Phi-Genesis computations.
- Report finite graph level, operator convention, boundary conditions, estimator and numerical range with quantitative claims.

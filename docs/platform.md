# Phi-Genesis Platform

Phi-Genesis is a reproducible computational workspace for studying finite Sierpiński-gasket graph spectra, boundary-condition changes, spectral counting, and proposed target-index selection rules.

## Main components

- **Numerical operators:** finite graph Laplacians and boundary-condition variants.
- **Spectral analysis:** decimation patterns, gap structure, counting functions, and inertia calculations.
- **Statistical audit:** preregistered selection tests, null models, power checks, and look-elsewhere controls.
- **Research records:** versioned protocols, result summaries, source code, and reproducibility instructions.
- **Navigation surfaces:** Material for MkDocs documentation, a separate interactive portal, and a separate research history.

## Platform boundary

This platform is a numerical research environment. It is not a proof assistant, a physical mass-generation model validated by observation, or a claim that the target indices have been independently derived.

See [Computational Architecture](computational-architecture.md) and [Reproducibility](reproducibility.md).
